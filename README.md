A full frontend + backend personal portfolio, built with Next.js 14 (App Router)
and Tailwind CSS, styled after Roman inscriptions on a cream/parchment background.

**Live:** https://jashwanth-portfolio-tan.vercel.app/

## What's inside

- **Frontend**: Next.js App Router pages, all statically generated.
- **Backend**: `/api/contact` — a serverless API route (runs as a Vercel
  Function) that receives the contact form submission. It currently logs the
  message; wire it to a real email service (see below) whenever you're ready.
- **Detail pages**: every project and every "Res Gestae" (achievement) entry
  is clickable and opens its own page at `/projects/[slug]` and
  `/achievements/[slug]`, with What I Did / How I Did It / Results sections.
- All content lives in `data/projects.ts` and `data/achievements.ts` — edit
  those two files to add, remove, or update anything without touching layout code.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repo.
2. Go to vercel.com → **Add New Project** → import the repo.
3. Framework preset: Next.js (auto-detected). No environment variables required
   to deploy as-is.
4. Deploy. That's it — the `/api/contact` route deploys automatically as a
   serverless function, no separate backend hosting needed.

## Wiring the contact form to real email

Right now `app/api/contact/route.ts` just logs submissions to the function's
console (visible in Vercel's function logs). To actually receive them:

1. Sign up for [Resend](https://resend.com) (or SendGrid).
2. `npm install resend`
3. In `app/api/contact/route.ts`, replace the `console.log` line with a call
   to send yourself an email using your API key (stored as a Vercel
   Environment Variable, never hardcoded).

## Before you publish

- Replace `[email protected]` in `components/Footer.tsx` with your real email.
- Replace the empty `href="#"` LinkedIn link in `components/Footer.tsx` with
  your LinkedIn URL.
- After your first Vercel deploy, copy your live URL into `metadataBase` in
  `app/layout.tsx` — this is what makes the social-share preview card (the
  image shown when you paste the link into LinkedIn/WhatsApp/Twitter) point
  at the right place. The card itself is auto-generated by
  `app/opengraph-image.tsx` — edit that file to restyle it.
- The browser tab icon (`app/icon.svg`) is a simple column emblem — swap it
  for anything else by replacing that file.
